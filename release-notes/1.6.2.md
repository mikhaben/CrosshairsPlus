## [1.6.2] - 2026-10-14

### WoW 12.1.5 Compatibility

**Changed**
- Bumped supported interface version to 120105 for the current Midnight patch (12.1.5).

**Fixed**
- Class color mode no longer errors on targets whose identity the game hides. Since 12.1.x, `UnitClass` returns a secret value for those units; the crosshair now falls back to the reaction color for them.

**Verified**
- `UnitIsUnit`, `C_NamePlate.GetNamePlateForUnit` and the other unit APIs the crosshair uses are unchanged in 12.1.0 and 12.1.5.
